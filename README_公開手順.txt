# かたく里 クリスマスビンゴ大会（本番サーバー版）

## このパッケージについて
既存のクリスマスデザインを引き継ぎ、Node.js + Express + Socket.IO で複数端末をリアルタイム同期する構成です。
参加者は公開URLをChromeで開き、名前を入力するだけです。参加上限は30人です。

## Renderへの公開
1. このZIPを解凍し、GitHubの新しいリポジトリへ全ファイルをアップロードします。
2. Renderにログインし、New + → Blueprint を選択してGitHubリポジトリを接続します。
3. `render.yaml` の設定を読み込ませてデプロイします。
4. `ADMIN_PASSWORD` の値をRenderのEnvironmentで設定します（主催者だけが知るパスワード）。
5. デプロイ完了後に発行される `https://....onrender.com` が参加者用URLです。

## 注意
- この設定はRender StarterのWeb Serviceと1GB Persistent Diskを使う想定です。無料Web Serviceはスリープや永続保存の制約があるため、本番イベントには推奨しません。
- `ADMIN_PASSWORD` は必ず推測されにくい独自のパスワードに変更してください。チャットに書いたり参加者へ共有しないでください。
- 管理者セッションは12時間で期限切れになります。
- BGMはブラウザ内で生成する簡易メロディです。著作権のある市販音源を配信する機能ではありません。ブラウザの自動再生制限により、参加者側で最初の操作後に音が有効になります。
- 参加者カード、抽選番号、景品、チャットはサーバーのJSONファイルに保存されます。RenderのPersistent Diskが必要です。
- 本番開催前に、管理者1台＋参加者2台以上で、参加・再接続・抽選・リーチ・ビンゴ・リセット・チャット・BGMを必ずテストしてください。
